Usage: forge-doctor-api scan [OPTIONS] [target]

§177 full scan: every deterministic pipeline + optional §178 gate.

┌─ Arguments ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
target <str> Project directory. [default: .]
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Options ────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
--fail-on <str> §178 gate categories, comma-separated: breaking,security,policy.
--baseline <str> Baseline contract file/dir for the breaking gate.
--policy <str> Extra policy file/dir merged into evaluation.
--format <str> console | json | jsonl | sarif | agent | report (full DoctorReport). [default: console]
--out <str> Write the export to a file.
--stats-timing Record per-analyzer wall time in report.stats (non-canonical; excluded from deterministic hashing).
--incremental Reuse cached analyzer models under .forge-doctor/cache/ (findings always recompute).
--help Show this message and exit.
