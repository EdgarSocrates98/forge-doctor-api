# Devin project config — forge-doctor-api

independent verification and diagnosis of API engineering.

- CLI: `forge-doctor-api` (see AGENTS.md for the operating contract).
- Obsidian export: `forge-doctor-api obsidian status|scan|preview|sync-plan|history` (read verbs pre-allowed in `config.json`; `export`/`export-note` mutate the vault and stay gated).
- `config.json` only declares `permissions` (repo-declarable keys); user-level settings are out of scope.
