## Assumptions (smallest reversible)

- A1: `Finding.id` = check id (kept field name from 001 rather than renaming to `check_id`). Per-instance identity = (id, entity_ids, source_location). Rename later if a consumer needs instance ids.
- A2: check id = 2–10 uppercase letters + 3–4 digits. Covers `OAS001`, `APISEC001`; no namespace registry (out of scope).
- A3: `Severity` has no UNKNOWN; uncertainty = `Confidence.UNKNOWN` + `UnknownFact` (carried over from 001 A4). UNKNOWN confidence without unknowns rejected.
- A4: `remediation` optional (`None`), but non-blank when set. `description` required.
- A5: `SourceLocation` = path/line/column only — no JSON pointer / end-line until a spec consumes them (SARIF region start fits).
- A6: missing `evidence_kind` → `ModelError` via `from_dict`; direct Python construction w/o kwarg → dataclass `TypeError` (still a hard failure). `None`/strings → `ModelError`.
- A7: redaction biased to over-mask: sensitive key masks whole subtree; header-like `Key: value` masks to end of line; unquoted pair values end at whitespace/`&"',;}<>` (so `#fragment` after a secret is masked too). Bearer/Basic bare credentials masked only when ≥16 chars or ≥8 with digit/`=` (avoids mangling prose like "Bearer authentication").
- A8: `schema_version` format `MAJOR.MINOR`; no rejection of other versions yet (no migration policy defined).
- A9: export sorts findings → producer order never leaks.

## Open risks

- R1: regex redaction is heuristic: secrets under non-obvious key names (`credentials`, `private_key`, `session`) or free-form prose not masked. Extend `_SENSITIVE_SUFFIXES` + `_KEY` together (they must stay in sync).
- R2: redacted payload ≠ original → round-trip equality only holds for secret-free models (by design).
- R3: redaction runs on every `to_dict()` — cost O(size) regex passes; fine now, revisit for 10k+ finding exports (§170).
- R4: `export.py` imports private `_require_text` from models; acceptable inside `core`, but promote if more modules need it.
- R5: Python 3.11–3.13 matrix not exercised locally (env is 3.14).
