## Assumptions (smallest reversible)

- A1: models = stdlib frozen `kw_only` dataclasses; no pydantic (deps limited to typer/rich).
- A2: determinism: sorted keys at every level, mappings sorted, datetimes → UTC ISO 8601, sets rejected at serialize time (`ModelError`), compact JSON, `allow_nan=False`. Tuple order = caller order (meaningful, not re-sorted).
- A3: timestamps optional + injected; naive datetimes rejected. Clock only via `ProjectContext.clock`; `now()` raises if absent.
- A4: `Confidence` = HIGH/MEDIUM/LOW/UNKNOWN (UNKNOWN first-class). `Severity` = CRITICAL/HIGH/MEDIUM/LOW/INFO (no UNKNOWN; unknowns go to `UnknownFact`). Assumed to match Forge Doctor Data conceptually — not verified against that repo.
- A5: `Finding` minimal (id, title, severity, confidence, evidence_kind, evidence, entity_ids, unknowns). Spec 002 owns check-id format, source_location, remediation hint, schema/tool version, redaction.
- A6: `Entity.id` validated as `{kind}:{domain}:{identifier}` with prefix == `kind` (§9).
- A7: placeholder CLI commands print `forge-doctor-api <cmd>: not implemented` to stderr, exit code 3 (distinct from 0 success and Click usage error 2).
- A8: pytest `--basetemp=.pytest-tmp` — host `%TEMP%\pytest-of-edgar` denied access (WinError 5); project-local basetemp keeps tests hermetic. Revert if CI prefers default.
- A9: `license` omitted from pyproject — product decision, not taken.
- A10: tests run from source via `pythonpath = ["src"]`; package not installed in this env.
