# Grill Gate

- Owner: project owner; decisions from `prompt_evo_rc_hardening.md` Phase 1.
- Problem: there is no frozen inventory of what is public, no
  per-surface stability class, and no recorded baseline this RC
  wave can be measured against. "Contract stability > new features"
  needs a written contract to stabilize.
- Out of scope: changing any surface; bumping version; publishing.
  This spec records reality and freezes the vocabulary — it does not
  redesign.
- Review failure: a "public surface" doc that lists directories
  instead of named, graded surfaces; classes invented ad hoc;
  baseline artifact generated by hand instead of reproducibly.
- Riskiest assumption: that a deterministic baseline generator can
  produce identical bytes across runs — RESOLVED by sorting,
  no wall-clock, and a `--check` regeneration-diff like sbom.py.
- Smallest acceptable: `docs/rc-policy.md` (stability classes +
  change rules), `docs/public-surface.md` (inventory with class per
  surface), `factory/rc_baseline.py` emitting
  `docs/rc-baseline.json` with `--check` mode, plus tests.

# Context

Phase 1. Existing: `cli/catalog.py` already grades CLI commands
(STABLE/EXPERIMENTAL); `contracts/version.py` versions the wire
family; `output-contract.md` documents report shapes. Missing: a
single stability-class vocabulary across all surfaces, a named
inventory, and a machine-checkable baseline artifact.

# Acceptance Criteria

- `docs/rc-policy.md` defines stability classes:
  STABLE / WIRE / UX / EXPERIMENTAL / INTERNAL / DEPRECATED, the
  change rule for each (what may change in a MINOR/PATCH/major of
  the relevant axis), and the RC discipline pointer.
- `docs/public-surface.md` inventories every public surface by name
  with its class: CLI commands/subcommands (all), SDK exports
  (`__all__`), MCP tool names + resources, `doctor://` URIs,
  Forge protocol models, `forge-contracts/1` schemas, output
  contract fields, check-id namespaces, plugin manifest format.
- `factory/rc_baseline.py` (stdlib only) emits
  `docs/rc-baseline.json` — deterministic artifact recording:
  version, python_requires, classified python versions, CLI command
  count, MCP tool count, `forge-contracts` version, lab scenario
  count, OSS corpus slice count, test-file count, scale baseline
  scales/headroom, SBOM dep count. `--check` regenerates and diffs.
- `tests/test_rc_baseline.py`: artifact is valid JSON with the
  pinned keys; `--check` passes against the committed file; the
  generator is deterministic (two runs byte-identical).
- `docs/index.md` or equivalent links the three new artifacts.
- pytest/ruff/mypy pass.

# Constraints

- No new runtime deps; factory script is stdlib-only.
- Baseline records facts, not targets — no scores, no grades.
- Keep version 0.1.0 (AGENTS.md hard rule unchanged by this spec).
