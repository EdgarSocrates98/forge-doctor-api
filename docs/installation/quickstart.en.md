# Quickstart — Forge Doctor API (EN)

Three commands:

```bash
git clone <forge-doctor-api>
cd forge-doctor-api
./setup.sh        # Windows: .\setup.ps1
```

Then, from any project:

```bash
forge-doctor-api scan .
```
