# forge-doctor-api + GitHub Copilot CLI

```bash
cd ~/meu-projeto
python scripts/forge_install.py install --yes
```

A instalação escreve blocos gerenciados `forge:*` em `AGENTS.md` +
`AGENT_PROTOCOL.md` e o registro `.forge/context/`. Este forge hoje não
publica mirrors em `.github/` nem `.agents/`. Suporte estrutural — a
execução real no Copilot é registrada como pendente na matriz de
aceitação até validação em ambiente real.
